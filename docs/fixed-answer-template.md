# 固定答题框与完整性校验

同一套答题卡的框位置固定时，应在试卷上配置`answer_template`。每个框有稳定ID、页号、归属题号、可选小问号、归一化坐标和阅读顺序。一个小问允许多个框或跨页续答；多个小问共用一个大框时，小问号留空，按整题共享框处理。

固定模式按模板取框，不调用布局模型，不使用动态框的扩边规则。空白框也提取并保留。当前要求页面已转正且与模板对齐；归一化坐标支持扫描分辨率变化，宽高比偏差超过2%会明确失败。它不能自动校正裁边、平移、透视或页序错误；页图必须按模板顺序提交。

## 配置模板

新建试卷时提交如下完整请求：

```json
{
  "title": "单题多框示例",
  "questions": [{
    "id": "17",
    "stem": "这里填写完整题干，也可使用question_assets",
    "reference": "这里填写完整参考解答，也可使用reference_assets",
    "max_score": "15"
  }],
  "answer_template": {
    "pages": [{
      "width": 1000,
      "height": 1400,
      "boxes": [
        {"id": "q17-part1", "question_id": "17", "subquestion_id": "1", "bbox": [0.1, 0.1, 0.9, 0.45], "order": 0},
        {"id": "q17-part2", "question_id": "17", "subquestion_id": "2", "bbox": [0.1, 0.5, 0.9, 0.9], "order": 1}
      ]
    }]
  }
}
```

`pages`数组下标就是从0开始的页号。`width`、`height`是对应模板页的参考尺寸。`bbox`为`[x0,y0,x1,y1]`，坐标在0到1之间，表示固定页面坐标系中的矩形。`order`在同一大题的所有框中唯一，决定跨框阅读顺序；不要求编号连续。

模板必须覆盖这份试卷的全部主观题，不能包含未知题号；框ID全局唯一，同页的不同框不能重叠。可以登记没有主观题框的页面。框坐标直接用于裁切，系统不会根据学生字迹重新移动框的位置。

已有试卷可调用`PUT /v1/exams/{exam_id}/answer-template`，请求体直接是上述`answer_template`对象，仍需覆盖该试卷的全部题目。配置过程不调用模型、不修改评分细则或预算。每个新批次保存当时的模板快照及内容哈希，之后修改试卷模板不会影响旧批次。已有未配置模板的批次继续使用其原流程。

## 提交学生输入

整卷输入沿用`kind=paper`与有序`pages`，页面数必须与模板完全一致；选题批次仍提供完整页列表，后台只处理所选题目的框。

按题输入须明确说明每张图片属于哪个框，`assets`与`box_ids`逐项对应：

```json
{
  "exam_id": "ready-exam-id",
  "question_ids": ["17"],
  "strategy": "B",
  "budget_cny": "0.50",
  "candidates": [{
    "candidate_id": "candidate-001",
    "kind": "question",
    "answers": [{
      "question_id": "17",
      "assets": ["part2-image-id", "part1-image-id"],
      "box_ids": ["q17-part2", "q17-part1"]
    }]
  }]
}
```

输入数组可以不是阅读顺序，后台会按模板重排。按题图片应已是该框的完整内容，系统不再套用整页坐标裁切。即使某框空白，也应提交它的空白图。缺少、重复、多余、未知框以及遗漏页面会在提交阶段返回422，不产生模型调用。未配置模板的试卷继续接受旧`assets`形式，且保持原幂等指纹；它不具备固定框完整性保证。

## 提取、校验与评分

输入准备按模板产生每个框的处理图片，保存`box_id`、`subquestion_id`、原图ID、实际裁图坐标、模板坐标、页号、顺序和模板版本。像素完全相同的两个框仍分配不同处理图片ID，避免空白框或重复内容因资产去重而失去来源身份。

评分前再次核对该题的完整框ID集合与模板版本；不完整的持久化检查点会明确失败，不继续评分。模型接收本题全部框及其小问映射，同一小问跨框合并阅读，整题共享框保持共享。结果继续保存逐评分点得分、理由和转写证据，并增加`answer_template_version`。

当前程序检查框是否收齐、证据是否存在以及分值约束；框的小问归属同时提供给评分模型和结果使用者。它不能独立证明模型的小问匹配或数学判断正确，不应据此宣称准确率达标。

## 数据库升级与验证

部署新代码后先运行`ai4edu init-db`，为`exams`和`jobs`增加可空JSON字段。迁移保留原试卷、批次、成绩和预算；原记录的模板为空。

测试覆盖同题多框、第二框独有答案、跨页续答、相同空白框、框缺失或重复、选题提取、模板更新隔离、评分前检查点校验、旧按题指纹和旧表迁移。该功能没有新增教师审核、自动补框、重试或错误后切换定位模型的步骤。
